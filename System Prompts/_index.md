# System Prompts 인덱스

> 이 파일은 AI가 시스템 프롬프트를 찾을 때 유일하게 참조하는 목록입니다. 아래 표에 없는 파일은 AI가 열지 않습니다. 새 프롬프트를 추가하면 이 표에 한 줄만 추가하세요.
>
> 분류는 폴더보다 태그를 우선합니다. 폴더는 코딩·글쓰기·게임플레이 같은 대주제 몇 개로만 얕게 유지하고, 세부 분류·교차 속성(톤, 용도, 대상 모델 등)은 각 프롬프트 파일 상단 frontmatter의 태그로 답니다. **AI가 실제로 파일을 열 때는 아래 "경로" 열만 사용합니다** — 태그·위키링크는 사람이 Obsidian에서 훑어보고 분류하기 위한 것이고, GitHub 커넥터 등 일부 접근 경로는 위키링크를 해석하지 못하기 때문에 경로는 항상 정확한 상대 경로로 적어둡니다.

| 이름 | 태그 | 경로 | 한 줄 설명 |
|---|---|---|---|
| (예시) [[코드리뷰어]] | #코딩 #리뷰어 #엄격함 | System Prompts/코딩/코드리뷰어.md | PR 리뷰용 깐깐한 시니어 리뷰어 페르소나 |
