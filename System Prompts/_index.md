# System Prompts 인덱스

> 이 파일은 AI가 시스템 프롬프트를 찾을 때 유일하게 참조하는 목록입니다. 아래 표에 없는 파일은 AI가 열지 않습니다. 새 프롬프트를 추가하는 방법은 [[시스템 프롬프트 작성 규칙]]을 따르세요.
>
> 분류는 폴더보다 태그를 우선합니다. 폴더는 필요해질 때만 대주제 몇 개로 좁게 만들고, 세부 분류·교차 속성(톤, 용도, 대상 모델 등)은 각 프롬프트 파일 상단 frontmatter의 태그로 답니다. **AI가 실제로 파일을 열 때는 아래 "경로" 열만 사용합니다** — 태그·위키링크는 사람이 Obsidian에서 훑어보고 분류하기 위한 것이고, GitHub 커넥터 등 일부 접근 경로는 위키링크를 해석하지 못하기 때문에 경로는 항상 정확한 상대 경로로 적어둡니다.
